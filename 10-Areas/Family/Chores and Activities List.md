## How to use this list

Each chore should be written so a kid can understand what “done” means without needing a parent to explain every step.

Use this format:

```markdown
### Chore name
- Status: available / paused / retired
- Estimated time: X minutes
- Allowance fee: $X
- Good for: Connor / Madison / McKenzie / any kid
- Parent check: what must be true before payment

Steps:
1. First clear action.
2. Second clear action.
3. Third clear action.
4. Optional fourth action.
5. Optional final check.
```

Payment rule: allowance is paid when the parent check is met, not just when the kid says “done.” Tiny but important legal department stuff.

## Fee ideas to decide

Use simple bands so the system does not become a negotiation hostage situation:

- Tiny chore, 5-10 minutes: $1-$2
- Small chore, 10-20 minutes: $2-$4
- Medium chore, 20-45 minutes: $5-$10
- Big chore, 45-90 minutes: $10-$20
- Gross / hard / outdoor chore: add $2-$5 bonus if done well
